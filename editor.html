개요

두 가지 기능을 제공합니다: 몬스터 이동 경로 설정과 몬스터 난이도 설정.
상단 탭에서 모드를 전환하며, 각각 코드를 생성해 게임 파일에 붙여넣습니다.

🗺 경로 설정 탭

개요

배경 이미지 위에 51×33 격자를 표시합니다. 셀을 클릭해 꺾임 지점(웨이포인트)을 순서대로 지정하면 풍선 이동 경로(PATH_WP)가 자동 생성됩니다.

작업 순서

1
이미지에서 경로가 꺾이는 지점을 파악합니다. 각 셀 안의 col,row 좌표를 확인하세요.
2
첫 번째 꺾임 지점 셀을 클릭합니다. 이후 꺾임 지점을 순서대로 클릭해 경로를 이어갑니다.
3
첫 웨이포인트의 row → 왼쪽 엣지(START), 마지막 row → 오른쪽 엣지(END)가 자동 연결됩니다. 대각선 경로도 허용됩니다.
4
📋 코드 복사 → 게임 파일의 PATH_WP 선언부에 붙여넣습니다.

조작

클릭웨이포인트 추가 — 대각선 포함 모든 방향 가능
드래그기존 웨이포인트를 다른 셀로 이동
우클릭마지막 웨이포인트 삭제
↩ 되돌리기마지막 웨이포인트 하나 제거
🗑 초기화모든 웨이포인트 삭제

화면 표시

초록 테두리 — 추가 가능 / 빨간 테두리 — 추가 불가
⚔ 난이도 설정 탭

개요

각 웨이브에 등장할 몬스터의 종류·수량·등장 간격을 설정합니다. 전역 설정(초기 생명, 초기 골드, HP/속도 배율)도 조정할 수 있습니다.

작업 순서

1
상단 전역 설정에서 초기 생명, 초기 골드, HP/속도 배율을 입력합니다.
2
웨이브 헤더를 클릭해 펼치면 몬스터 그룹 목록이 표시됩니다.
3
각 그룹의 종류 · 수량 · 간격(iv) · 시작(at)을 수정합니다.
4
+ 그룹 추가로 같은 웨이브에 여러 종류의 몬스터를 섞을 수 있습니다.
5
📋 WAVES 코드 복사 → 게임 파일의 WAVES 배열 + initGame()에 붙여넣습니다.

필드 설명

종류몬스터 타입 선택 (슬라임~메가보스)
수량해당 그룹에서 등장할 몬스터 수
간격 (iv)몬스터 한 마리씩 등장하는 틱 간격 (작을수록 빠르게 등장)
시작 (at)이 그룹의 첫 등장 시작 틱 (0 = 웨이브 시작 즉시)
